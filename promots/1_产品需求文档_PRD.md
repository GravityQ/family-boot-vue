# 1. 产品需求文档 (PRD) - 家人在线

**项目名称**: 家人在线 (Family Online)
**版本**: v1.0.0
**状态**: 正式版
**最后更新日期**: 2024-05-22

---

## 1. 项目概述

### 1.1 产品定位
“家人在线”是一个帮助同源同宗同族的人分享族人信息、构建家族记忆的数字化平台。
*   **核心载体**: 微信小程序（面向普通族人，轻量级交互） + Web 管理后台（面向家族管理员，深度管理）。
*   **核心价值**: 解决传统修谱“协作难、查询难、保存难”的痛点，通过“可视化图谱”和“严谨审核流”实现家族文化的数字化传承。

### 1.2 目标用户
1.  **家族创建者/管理员**: 需要高效管理成百上千人的家族数据，维护信息的准确性。
2.  **普通族人**: 希望能快速找到自己的根源，浏览家族关系，并便捷地录入自己的小家庭信息。
3.  **老年长辈**: 需要大字体、操作简单的界面来查看族谱和老照片。

## 2. 角色与权限体系 (RBAC)

系统采用严格的权限控制，确保数据隐私与安全。

| 角色 | 适用人群 | 核心权限 | 关键业务规则 |
| :--- | :--- | :--- | :--- |
| **普通用户** (User) | 注册后的普通族人 | 1. **浏览**: 查看已加入家族的图谱、成员详情。<br>2. **搜索**: 全局搜索家族（仅展示脱敏概况）。<br>3. **提交**: 申请加入家族、新增/修改/纠错成员信息。<br>4. **收藏**: 收藏关注的家族。 | **强审核**: 所有增删改操作均为“申请制”，必须由家族管理员审核通过后方可生效。 |
| **家族管理员** (Family Admin) | 家族创建者或被授权者 | 1. **家族管理**: 修改家族简介、公告、隐私设置。<br>2. **成员管理**: 直接增删改成员数据（免审核）。<br>3. **审核**: 处理普通用户的提交申请（通过/驳回）。<br>4. **权限**: 任命其他管理员，移除违规成员。 | **最高话语权**: 对本家族数据拥有最高管理权。 |
| **系统管理员** (System Admin) | 平台运营人员 | 1. **全平台监管**: 审核“新建家族”申请。<br>2. **违规处理**: 封禁违规用户或家族。<br>3. **系统配置**: 维护数据字典、公告等。 | 仅介入家族创建审核与全局风控，不干涉家族内部日常事务。 |

## 3. 核心业务流程

### 3.1 家族创建流程
1.  用户（任意角色）在小程序/Web端填写“创建家族申请”（名称、姓氏、祖籍、字辈）。
2.  系统校验名称唯一性。
3.  生成“待审核”家族记录。
4.  **系统管理员**后台审核 -> 通过。
5.  用户自动成为该家族的“家族管理员”。

### 3.2 成员录入与协作流程
1.  **场景 A（管理员录入）**: 管理员直接在后台/小程序添加成员 -> 数据直接写入正式表 -> 更新图谱。
2.  **场景 B（普通用户录入）**:
    *   用户在图谱中点击“添加子女/配偶”或“纠错”。
    *   填写表单 -> 提交。
    *   系统生成 `AuditLog`（审核记录），状态为 `PENDING`。
    *   家族管理员收到通知 -> 查看对比详情（Old vs New）。
    *   管理员点击“通过” -> 系统更新正式表；或点击“驳回” -> 用户收到驳回原因。

### 3.3 跨家族关联流程 (高级)
1.  在录入配偶（如妻子）时，若妻子已在平台建立了原生家族。
2.  可输入妻子的 `FamilyID` 或 `MemberID` 进行搜索绑定。
3.  绑定成功后，在丈夫的图谱中点击妻子，可跳转至妻子的原生家族图谱（需视对方隐私设置而定）。

## 4. 功能需求清单

### 4.1 家族管理 (P0)
*   **F01 创建家族**: 必填项包括名称（唯一）、主要姓氏、祖籍位置。
*   **F02 家族设置**: 设置封面图、家族简介、是否公开搜索。
*   **F03 家族列表**: 展示我管理的、我加入的、我收藏的家族。

### 4.2 成员管理与图谱 (P0)
*   **M01 可视化树谱**:
    *   支持**垂直视图**（传统吊线图）和**水平视图**（架构图）。
    *   支持手势缩放、拖拽、点击节点查看详情。
    *   **懒加载**: 针对超过 500 人的大家族，默认只加载 5 代，点击末端节点动态加载子节点。
*   **M02 成员详情卡片**: 展示姓名、生卒年、行传、直系亲属导航。
*   **M03 复杂关系录入**:
    *   支持**多配偶**（如续弦）。
    *   支持**离异/再婚**标记。
    *   支持**过继/抱养**关系标记。

### 4.3 寻根与搜索 (P1)
*   **S01 全局搜索**: 支持按“姓氏 + 地区 + 字辈”组合搜索。
*   **S02 隐私脱敏**: 未加入家族前，搜索结果隐藏详细树谱，仅展示家族概况。

### 4.4 消息与通知 (P2)
*   **N01 审核通知**: 管理员收到待办事项通知。
*   **N02 结果通知**: 用户收到申请通过/驳回通知。

---

## 5. 非功能需求

1.  **性能**: 小程序端首屏树谱加载时间 < 2秒。
2.  **并发**: 支持百人级同时在线浏览同一家族。
3.  **易用性**: 针对老年用户，提供“大字模式”或“简易版”界面。
4.  **数据安全**: 敏感信息（手机号、身份证、在世人住址）数据库加密存储，前端展示脱敏。
