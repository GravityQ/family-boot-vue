# 3. UI 交互设计规范 - 家人在线

**适用端**: 微信小程序 / 移动 Web
**版本**: v1.0.0
**设计风格**: 清新、人文、严谨

---

## 1. 视觉规范 (Visual Identity)

### 1.1 色彩体系 (Color Palette)
*   **主色调 (Brand Color)**: `#FF7D00` (橙色)
    *   *寓意*: 温暖、血缘、活力。用于主按钮、高亮标签、关键图标。
*   **辅助色**:
    *   **信息蓝**: `#1E88E5` (链接、次要操作)
    *   **成功绿**: `#4CAF50` (审核通过、状态正常)
    *   **警示红**: `#F44336` (驳回、删除、危险操作)
*   **中性色**:
    *   **背景**: `#F5F5F0` (浅米色，仿纸质/古籍质感，护眼)
    *   **卡片**: `#FFFFFF` (纯白)
    *   **一级文本**: `#333333` (标题)
    *   **二级文本**: `#666666` (正文)
    *   **分割线**: `#E0E0E0`

### 1.2 字体与排版
*   **字体**: PingFang SC (iOS), Roboto (Android), 思源黑体。
*   **字号**:
    *   导航标题: 18px (加粗)
    *   人物姓名: 16px (加粗)
    *   正文内容: 14px
    *   辅助说明: 12px
*   **无障碍**: 支持“长辈模式”，开启后整体字号放大 1.2 倍。

## 2. 核心页面布局 (Layouts)

### 2.1 树谱展示页 (Tree View) - P0
**交互逻辑**:
*   **画布**: 全屏 Canvas 区域，支持双指缩放、单指拖拽。
*   **布局切换**: 顶部浮动按钮，支持切换 [垂直吊线图] / [水平架构图]。
*   **节点样式**:
    *   **男性**: 矩形卡片 (淡蓝色边框)。
    *   **女性**: 圆角矩形卡片 (淡粉色边框)。
    *   **内容**: 头像 + 姓名 + (生卒年)。
    *   **连线**:
        *   实线: 血缘关系 (父子)。
        *   虚线: 婚姻关系 (配偶)。
*   **操作**: 点击节点 -> 底部弹出“半屏详情面板”。

### 2.2 成员详情页 (Profile)
**布局结构**:
1.  **顶部头图**: 个人封面背景 + 圆形大头像。
2.  **基本信息区**: 姓名、性别、字辈、籍贯、生卒日期。
3.  **亲属导航区**:
    *   **父母**: 两个卡片，点击跳转。
    *   **配偶**: 横向滚动列表（支持多配偶）。
    *   **子女**: 网格列表。
4.  **行传区**: 纯文本区域，展示生平事迹（支持展开/收起）。
5.  **底部操作栏**: [纠错] [分享] [补充资料]。

### 2.3 录入表单页 (Forms)
**设计原则**: 减少键盘输入，多用选择器。
*   **日期**: 使用系统的 DatePicker (支持仅选择年份)。
*   **关系**:
    *   父亲/母亲: 默认带入当前节点的上级，支持搜索修改。
    *   配偶: 支持从现有成员选择 或 手动新建。
*   **校验反馈**: 实时校验必填项，未通过时输入框变红并提示。

## 3. 交互细节 (Interactions)

### 3.1 加载与反馈
*   **Loading**: 树谱加载时，显示类似“树木生长”的动效，而非枯燥的转圈。
*   **Empty**: 数据为空时，显示插画（如一本合上的古书），引导“开始修谱”。

### 3.2 审核流程交互
*   **提交后**: 页面Toast提示“申请已提交，请等待管理员审核”，并在个人中心显示红点。
*   **审核详情**:
    *   采用 **左右/上下对比视图**。
    *   左侧: 原数据 (灰色)。
    *   右侧: 新数据 (高亮橙色)。
    *   差异点: 自动高亮显示。

### 3.3 移动端手势
*   **双击节点**: 快速进入详情。
*   **长按节点**: 唤出快捷菜单 (添加子女、添加配偶、编辑)。

## 4. 附录：图标规范 (Icons)
使用线性图标风格，线条宽度 2px。
*   🏠 **首页/家族**: 传统屋檐图标
*   🌳 **图谱**: 树形分叉图标
*   🔍 **搜索**: 放大镜
*   👤 **我的**: 人像剪影
*   ✏️ **编辑**: 毛笔样式 (呼应族谱主题)
