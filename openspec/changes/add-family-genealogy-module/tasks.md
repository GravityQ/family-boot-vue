## 1. 实现（Implementation）
- [ ] 1.1 后端模块：按照芋道既有规范，搭建 `yudao-module-family`（`-api` + `-biz`）基础结构。
- [ ] 1.2 数据库：基于 TDD 设计，创建并维护 `family`、`member`、`family_unit`、`audit_log` 等表及 MySQL 初始化/迁移脚本。
- [ ] 1.3 App API：实现 `/app-api/family/v1` 下的家族搜索/详情、成员树谱、成员详情、成员申请新增与申请修改等接口。
- [ ] 1.4 Admin API：实现 `/admin-api/family` 下的审核工作台（分页、通过、驳回）以及家族管理员直接新增/删除成员等接口。
- [ ] 1.5 安全与权限：将上述 API 接入现有认证与多租户体系，区分普通用户 / 家族管理员 / 系统管理员的访问与操作权限。

- [ ] 1.7 前后端契约：与小程序和管理后台前端对齐请求/响应 DTO/VO 结构（前端可能在其他仓库中实现）。
